# RetrolightGb

RetrolightGb is a Gameboy emulator built with Kotlin Multiplatform and Compose Multiplatform, allowing it to run on Android, iOS, and desktop (Windows, macOS, Linux).

## Platforms

* **Android**
* **iOS**
* **Desktop:**
    * Windows
    * macOS
    * Linux

## Getting Started

1.  Clone the repository: `git clone https://github.com/your-username/RetrolightGb.git`
2.  Open the project in IntelliJ IDEA or Android Studio.

## Technology Stack

*   **Kotlin Multiplatform:** For a single codebase across different platforms. [Learn More](https://kotlinlang.org/docs/multiplatform.html)
*   **Compose Multiplatform:** For building the user interface.
